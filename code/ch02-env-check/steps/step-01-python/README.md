# step-01-python:最小自检脚本

只检查一件事:**Python 版本是否 ≥ 3.12**。

目的是先把脚本的整体骨架立起来——一个 `results` 列表收集每项检查的
(状态, 说明),最后统一汇总打印。后面几步都只是往这个列表里加检查项。

## 运行

```bash
python check_env.py
```

或用本书推荐的 uv:

```bash
uv run python check_env.py
```

## 预期输出

```
==================================================
GIS 开发环境检查结果
==================================================
  ✓  Python 版本 3.12
==================================================
🎉 所有检查通过,可以开始学习了!
```
