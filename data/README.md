# 数据集

本目录管理教材中使用的所有数据集。

## 原则

1. **不直接存大数据**。本仓库只存数据清单和下载脚本。
2. **所有数据必须有明确许可证**。
3. **所有数据通过脚本可重现获取**。

## 使用方式

查看 `sources.yaml` 了解可用数据集,然后运行对应下载脚本:

```bash
python data/scripts/download_china_admin.py
```

下载的数据会保存到 `data/<dataset-id>/`(已在 `.gitignore`)。

## 贡献新数据源

新增数据源请在 `sources.yaml` 中补充条目,并提供:
- 明确的许可证信息
- 稳定的下载地址
- 可重现的下载脚本
- SHA256 校验和
