# 第 3 章 习题

> 配套正文:[`book/ch03-prompt-basics/`](../../book/ch03-prompt-basics/)。
> 参考答案见教师专用仓库(申请方式见 [`../../solutions/README.md`](../../solutions/README.md))。

## 基础

1. 用自己的话列出 Prompt 五要素,并举例说明每一个要素对 GIS 场景特别关键的原因。
2. 本章提到 GIS 领域有四类特有的歧义来源。请你回忆一次自己(或朋友)做 GIS 任务时遇到过的歧义,分类到这四类里的哪一类。
3. "请先复述我的需求"这句话为什么有用?如果你是 AI,加了这句和没加这句,你的回复会有什么差异?

## 进阶

4. 给下面这句粗糙的 Prompt,用五要素结构改写一版:
   > "帮我把这些数据处理一下,然后画个图"

   请你先虚构一个合理的真实场景(比如"这些数据"是什么、"处理"要做什么、"画个图"给谁看),再改写。
5. 翻出你过去随便和 AI 聊过的一次对话(不一定要 GIS 相关)。用本章的方法**为那次对话重写第一条 Prompt**,估计一下重写版能节省多少轮对话。
6. 本章模板 B("不要写代码,先讨论")和模板 A(直接下单)在什么情况下分别适用?写一份判断标准。

## 挑战

7. 挑一个你**真实想做的 GIS 小项目**(不管是课程作业还是自己的想法),为它设计一套完整的多轮 Prompt 剧本:第 1 轮讨论方案、第 2 轮确定技术选型、第 3 轮让 AI 先复述、第 4 轮开始写代码……列出预计每轮的 Prompt 内容,以及预期 AI 的回复形态。
8. 开始你的个人 Prompt 模板库。新建一个 `~/my-prompts/` 目录(或在你本书的仓库里新建 `prompts/my/`),把本章七个模板抄进去,**并至少原创一个属于你自己的高频场景模板**。这份模板库会贯穿本书剩余章节,每学完一章回来更新一次。
