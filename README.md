# GIS × AI 对话式编程

> 一本面向 GIS 专业本科生与研究生的教材,讲授如何用自然语言与 AI 协作完成 GIS 开发。

## 这本书讲什么

不是"AI 的历史与前景",也不是"又一本 Leaflet 入门"。

这本书回答一个具体问题:**当你是一名 GIS 专业学生,手里有 Cursor 或 Claude,如何把它真正用起来,独立完成一个从数据到前端的 GIS 项目?**

## 适合谁读

- GIS 专业本科三年级及以上学生
- GIS 方向研究生
- 有少量编程基础(学过 Python 或 JS 皆可),想快速上手 web GIS 开发的人

## 目录

- 第一部分 基础与心法(第 1–3 章)
- 第二部分 前端地图开发(第 4–5 章)
- 第三部分 空间数据与后端(第 6–9 章)
- 第四部分 综合与反思(第 10–12 章)
