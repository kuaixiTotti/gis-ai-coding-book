# 写作规范

## 单章工作流

1. **周一**:确定主题、列提纲、跑通核心代码示例(2h)
2. **周二至周四**:每天 1h 写作 + AI 对话记录整理(3–4h)
3. **周五**:配图、改稿、发布(2h)

## 每章必备元素

- [ ] 学习目标(3–5 条)
- [ ] 先修知识清单
- [ ] 至少 1 份真实 AI 对话记录
- [ ] 至少 1 个可运行完整示例
- [ ] 5 道课后习题(2 基础 + 2 进阶 + 1 挑战)
- [ ] 本章 Prompt 小结

## 禁止事项

- 不用 AI 对话的截图代替代码(截图会过时,代码要文字化)
- 不编造对话(所有对话必须真实发生过)
- 不使用有版权争议的数据集

## 代码示例规范

- 所有代码必须在 `steps/` 留下分步骤快照
- 每段代码前给出"意图说明"
- 错误示例必须明确标注"⚠️ 这是反例"
