# 风格指南

## 文字

- 中文与英文/数字之间加空格:例如 "使用 Leaflet 加载 GeoJSON"
- 专业术语首次出现给出英文原文:例如 "空间连接(spatial join)"
- 避免"我们"开头的句子堆砌,多用祈使句

## 代码

### Python
- 使用 `ruff` 格式化
- 类型注解从第 6 章开始引入
- 字符串默认用双引号

### JavaScript / TypeScript
- 使用 `prettier` 格式化
- 单引号字符串
- 分号结尾

### 命令行
- 提示符统一用 `$` (Unix) 或 `>` (Windows,仅在 Windows 特定场景)
- 多行命令用反斜杠续行

## 图表

- 所有图片放章节目录的 `screenshots/` 或 `figures/`
- 文件名:`fig-chXX-NN-description.png`
- 屏幕截图裁掉个人信息(头像、用户名等)

## 对话记录

- 用户消息用 "👤 用户:" 开头
- AI 消息用 "🤖 AI:" 开头
- 关键时刻用引用块标注:
  - 🟢 好的回答
  - 🟡 需要追问
  - 🔴 明显错误
