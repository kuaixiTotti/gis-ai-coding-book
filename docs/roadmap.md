## 单章工作流(两周制)

1. **上周周一(2h)**:`/new-chapter` 搭骨架 → 列提纲 → 跑通核心代码主线
2. **上周周中(3.5h)**:写正文前半,`/code-snapshot` 随手存 step
3. **下周周中(3h)**:写正文后半,`/format-dialogue` 对话入库、`/new-prompt` 沉淀、出习题
4. **下周周五(2.5h)**:`/style-check` → `style-reviewer` 审稿 → `code-tester` 验证 → 提交发布
