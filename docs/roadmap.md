- 周更:每周一发布一章初稿

## 单章工作流(摘自 writing-guide)

1. **周一**:确定主题、列提纲、跑通核心代码示例(2h)
2. **周二至周四**:每天 1h 写作 + 整理 AI 对话记录(3–4h)
3. **周五**:配图、改稿、按 style-guide 做格式检查、发布(2h)

## 配套工具(`.claude/`)

- `/new-chapter` — 周一搭当周章节骨架
- `/style-check` + `style-reviewer` agent — 周五发布前查规范、审稿
- `/new-prompt`、`/format-dialogue`、`/code-snapshot` — 写作过程中沉淀 Prompt / 对话 / 代码快照
- `code-tester` agent — 验证当周配套代码可运行
- 进度跟踪见根目录 `TASKS.md`
